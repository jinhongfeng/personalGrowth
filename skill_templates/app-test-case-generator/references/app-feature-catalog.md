##### Feature: 手机号验证码登录

- 功能 ID: LOGIN-001
- 所属式样书: 示例商城式样书 v1.0 / 2.1 登录
- 需求来源: PRD
- 功能目标: 注册用户可以使用手机号和短信验证码登录商城。
- 适用角色: 游客 / 注册用户
- 适用端: Web / H5
- 入口路径: 首页 -> 登录 -> 手机号登录
- 前置条件: 手机号已注册，短信服务在测试环境可用或已配置模拟验证码。
- 主流程:
  1. 用户进入手机号登录页。
  2. 输入已注册手机号。
  3. 点击获取验证码。
  4. 输入正确验证码。
  5. 点击登录。
- 业务规则:
  - 手机号必须为 11 位中国大陆手机号。
  - 验证码为 6 位数字。
  - 验证码 5 分钟内有效。
  - 登录成功后跳转到进入登录页前的页面。
- 字段规则:
  - 字段: 手机号
    类型: 文本
    必填: 是
    长度/范围: 11 位
    格式: 中国大陆手机号
    默认值: 无
    错误提示: 请输入正确的手机号
  - 字段: 验证码
    类型: 文本
    必填: 是
    长度/范围: 6 位
    格式: 数字
    默认值: 无
    错误提示: 请输入正确的验证码
- 状态流转:
  - 未登录 -> 已登录: 手机号和验证码校验通过。
- 权限规则:
  - 游客: 可访问登录页。
  - 已登录用户: 访问登录页时跳转到首页。
- 异常规则:
  - 验证码错误: 页面提示验证码错误，不登录。
  - 验证码过期: 页面提示验证码已过期。
  - 接口失败: 页面提示系统繁忙，请稍后重试。
- 数据规则:
  - 登录成功后用户信息在页面刷新后保持。
- 通知/埋点/日志:
  - 登录成功记录 login_success 埋点。
- 兼容性要求:
  - 覆盖 Chrome 最新版和主流移动浏览器。
- 验收标准:
  - 已注册用户输入正确手机号和验证码后可以成功登录。
  - 非法手机号、错误验证码、过期验证码均不能登录并展示明确提示。
- 已知限制:
  - 本示例不覆盖第三方登录。
- 补充说明:
  - 可用模拟验证码 123456。
